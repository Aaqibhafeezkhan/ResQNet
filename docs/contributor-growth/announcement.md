# Draft community announcement — not published

Want to make your first open-source contribution? Come help with ResQNet.

ResQNet is an experimental emergency mesh-messaging project for Android phones. It is open source so people can inspect its assumptions, reproduce results and improve the code and documentation together. Small, careful contributions help someone else build, test or understand the project.

We welcome Java, Android, React/TypeScript, documentation, accessibility and testing skills. Starter tasks include a simulator quickstart, copying a public fingerprint, listing simulator topologies and making the website easier to navigate. There are also intermediate replay-sharing and guided-demo opportunities.

We especially need real Android device testing. Even one phone can help with installation, permissions and UI feedback. Controlled multi-hop testing needs more setup; simulation results do not establish real radio performance. This is research software, not a dependable emergency service—please use dummy messages.

Browse [starter issues](https://github.com/Gautam-aman/ResQNet/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22), check current assignees, then comment `/assign` and wait for confirmation. Ask in the issue if you need guidance; use `/unassign` if plans change.

The [contributor guide](https://github.com/Gautam-aman/ResQNet/blob/main/CONTRIBUTING.md) covers setup and tests. The [device-testing guide](https://github.com/Gautam-aman/ResQNet/blob/main/apps/android/DEVICE_TESTING.md) explains how to report useful, redacted evidence. You do not need to be a mesh-networking expert to help.
